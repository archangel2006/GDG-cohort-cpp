## 1. Understanding the VS Code Interface

Some important components you'll use regularly:

- **Editor:** Where you write and edit your C++ programs.
- **Explorer:** View and manage your files and folders.
- **Extensions:** Install additional functionality and tools.
- **Integrated Terminal:** Execute commands, compile and run programs.

## 2. Terminal vs Output vs Debug Console

These are different panels available in the bottom section of VS Code.

| Panel | Purpose |
|---|---|
| Terminal | Execute commands, compile programs and run C++ code. |
| Output | Displays logs and messages generated by extensions and tools. |
| Debug Console | Inspect variables and evaluate expressions during debugging. |
| Problems | Displays detected errors and warnings in your code. |

**Integrated Terminal**

- Open using `Ctrl + ~`.
- Compile programs using `g++`.
- Execute compiled programs.
- Provide input through `cin` and view output through `cout`.

Example:

```bash
g++ main.cpp -o main
.\main.exe
```

**Output Panel**

- Displays messages and logs from VS Code extensions.
- Code Runner can display program output here by default.
- Interactive input may not work unless configured to run in the terminal.

**Debug Console**

- Used during debugging.
- Evaluate expressions and inspect variable values.
- Useful for understanding program execution.

**Remember:** For DSA practice, the integrated terminal should be your primary workspace for compiling and executing programs.

## 3. VS Code Extensions

Extensions add functionality to VS Code.

Open the Extensions Marketplace using `Ctrl + Shift + X`.

### Recommended Extensions

| Extension | Purpose |
|---|---|
| C/C++ (Microsoft) | IntelliSense, syntax highlighting, code navigation and debugging support. |
| C/C++ Extension Pack | Additional tools for C/C++ development. |
| Code Runner | Quickly execute code snippets and programs. |

<img width="2368" height="906" alt="image" src="https://github.com/user-attachments/assets/5518585f-ed38-463f-b1cc-ec45853ef296" />


**A few things to remember:**
- Extensions are additional tools, not compilers.
- Installing the C/C++ extension does not install GCC or G++.
- Code Runner is optional; learn to compile and execute programs through the terminal.

## 4. AI Coding Assistants

AI coding assistants can help with code explanations, debugging, suggestions and understanding unfamiliar concepts.

Some popular options include:

### GitHub Copilot

- AI-powered code completion.
- Chat-based code explanations.
- Suggestions while writing code.
- Agent mode for more complex coding tasks.

### Using AI Effectively for DSA

AI tools can help you:
- Understand compiler errors.
- Get explanations of unfamiliar C++ concepts.
- Generate edge cases for testing.
- Understand time and space complexity.
- Debug your implementation.

Avoid relying on AI to generate complete solutions without understanding the underlying logic. The goal is to develop your own problem-solving skills.

## 5. Useful VS Code Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl + Shift + X` | Open Extensions |
| `Ctrl + ~` | Open/Close Terminal |
| `Ctrl + S` | Save File |
| `Ctrl + Shift + P` | Open Command Palette |
| `Ctrl + /` | Toggle Comment |
| `F5` | Start/Continue Debugging |
| `F9` | Toggle Breakpoint |
| `F10` | Step Over |
| `F11` | Step Into |
| `Shift + F5` | Stop Debugging |
